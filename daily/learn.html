今日成果 · ArtCraft 办公三件套文档表格排版

1.WordCraft：纯 Rust 写的开源 Word 平替，16,362 星

storytold 的 ArtCraft 矩阵新成员，10 月 7 日建仓、三周涨到 1.6 万星。读写真 .docx，功能区、样式、表格、修订追踪、引用、邮件合并全有；修订批注、目录、脚注、四种引文格式（APA / MLA / Chicago / IEEE）都做全了。macOS / Windows / Linux / BSD / 网页全覆盖，Agent 可用 MCP 直接驱动。

🎯 对你的用处：熟食制作流程表、定投台说明这类文档，以后用它原生编辑 .docx、修订留痕，不用再把文件传到在线文档站。

收费：开源免费（MIT OR Apache-2.0）
来源：GitHub 仓库
https://github.com/storytold/wordcraft

2.GridCraft：纯 Rust 写的开源 Excel 平替，6,672 星

ArtCraft 矩阵的表格一件。500+ 函数、动态数组、LET 与 LAMBDA、结构化表引用，透视表、条件格式、迷你图、数据条全有，读写真 .xlsx；样张直接拿家庭预算与销售仪表盘当招牌。macOS / Windows / Linux / BSD / 网页全覆盖，MCP 可驱动。

🎯 对你的用处：定投复利台 20 年明细、持仓跟踪表（两只基金每日净值与浮亏）、熟食采购比价篮子，做成真 .xlsx：公式、透视表、条件格式一次建好，每天只填新数。

收费：开源免费（MIT OR Apache-2.0）
来源：GitHub 仓库
https://github.com/storytold/gridcraft

3.DesignCraft：纯 Rust 写的开源桌面出版工作室，4,853 星

ArtCraft 矩阵的排版一件，对标 InDesign。杂志级串接排版：一篇故事流过三栏、绕过引文框、页眉页脚自动跟；自家段落排版器管对齐、断字、行距。整本示例杂志是从代码排出来、再由自家渲染器导出的——“版式即代码”。

🎯 对你的用处：展示页、学习成果页、盘前预判卡的版式，按出版标准排；“版式写成代码、渲染出来就是成品”的思路可以抄过来做版式模板，改版只改模板参数。

收费：开源免费（MIT OR Apache-2.0）
来源：GitHub 仓库
https://github.com/storytold/designcraft

今日成果 · 修图、矢量与界面漫剧与 App

4.LightCraft：纯 Rust 写的开源 Lightroom 平替，14,861 星

ArtCraft 矩阵的调色一件。照片图库＋RAW 显影，非破坏性编辑：原片永远不动；32 位浮点、场景参照、宽色域管线，OkLCh 感知色彩空间算白平衡与三向色轮；8 段色彩混合器、预设与色彩配置文件齐全。样张敢拿安塞尔·亚当斯 1942 年《提顿山脉与蛇河》当招牌。

🎯 对你的用处：漫剧分镜图、标题卡底图做一套全剧通用调色预设（曝光、色温、电影感色轮一次定好、每集套用），色调不再漂移；中文 README 现成的，用着不费劲。

收费：开源免费（MIT OR Apache-2.0）
来源：GitHub 仓库
https://github.com/storytold/lightcraft

5.VectorCraft：纯 Rust 写的开源矢量插画工具，10,852 星

ArtCraft 矩阵的矢量一件，对标 Illustrator。钢笔贝塞尔、路径查找器、实时混合、剪贴蒙版全有；3D 旋转能直接转出带矢量 shading 的静物，两点透视网格上画建筑立面；还有尺寸标注工具，长度、角度、半径跟着图形走、自动更新。

🎯 对你的用处：漫剧海报标题字、游戏 UI 图标画矢量原稿，放大不糊、改色一键换；尺寸标注工具顺手能画熟食店价目牌与柜台布局图。

收费：开源免费（MIT OR Apache-2.0）
来源：GitHub 仓库
https://github.com/storytold/vectorcraft

6.FigCraft：纯 Rust 写的开源界面设计工具，3,632 星

ArtCraft 矩阵的界面一件，对标 Figma。画框、自动布局、组件与变体、矢量网络、样式、变量、原型全有；.fig 文件也能打开（尽力而为）。性能按“20,000 节点文件里新建一个节点不到一毫秒”标；文件是本机磁盘上的普通压缩包，无账号、无遥测。

🎯 对你的用处：做新 App 或改工作台、收藏夹界面之前，先画一版带自动布局的手机原型（组件变体一次定义、多屏复用、明暗主题一键切），定稿再写单文件 HTML，少走“写完才发现布局别扭、重写三遍”的弯路。

收费：开源免费（MIT OR Apache-2.0）
来源：GitHub 仓库
https://github.com/storytold/figcraft

今日成果 · 动态图形与声音漫剧制作

7.EffectCraft：纯 Rust 写的开源动态图形工作室，8,035 星

ArtCraft 矩阵的特效一件，对标 After Effects。合成、图层、关键帧、306 个特效、图层样式、表达式、3D 相机与灯光、渲染队列；Lottie 导入导出原生内置，动画做好直接进网页与 App；工程文件是能读的 JSON（.ecproj），版本控制里 diff 干干净净；音视频编解码全是纯 Rust，不用 FFmpeg。

🎯 对你的用处：漫剧标题卡、片头特效做 Lottie 动效嵌进展示页，零成本、真动态、不糊；.ecproj 用 JSON 存档的做法也值得学——分镜表、配音表以后也按“能 diff、能回滚”的格式存。

收费：开源免费（MIT OR Apache-2.0）
来源：GitHub 仓库
https://github.com/storytold/effectcraft

8.SoundCraft：纯 Rust 写的开源数字音频工作站，3,824 星

ArtCraft 矩阵的音频一件，对标 Pro Tools。多轨编辑、完整混音台（每轨 10 个插入＋10 个发送、总线、VCA、编组文件夹）、MIDI 编辑器带内置合成器、录音与混缩；每个动作都能被命令行、JSON 控制通道、MCP 调。注意：目前还是 pre-alpha 早期版本。

🎯 对你的用处：漫剧整幕配音（旁白、角色、音效、配乐）以后进它做多轨混音（音量自动化、淡入淡出、混响发送一次调好、每集套用）；现在还是早期版，先记下、等稳了再切生产。

收费：开源免费（MIT OR Apache-2.0）
来源：GitHub 仓库
https://github.com/storytold/soundcraft

今日成果 · Agent 直接出成品最值得看

9.answer-me-with-html：问难问题，直接给一页能看的 HTML，4,544 星

一个 Agent Skill：模型只写 Markdown 草稿，CLI 在 50 毫秒内排成带图的页面。实测 9 页手工 HTML 平均 4,893 token，其中 SVG 坐标与路径占 47%、CSS 占 15%、HTML 标签占 17%——这三样全由 CLI 写，模型只写占 21% 的文字，平均 612 token，8 倍省量、2.6 倍提速，数字全部可复现；同一套管线还能出讲解视频（省约 18 倍 token、快约 12 倍）。Node.js 20+ 即可，支持 Claude Code / Codex / Cursor / OpenCode / DeepSeek Harness。

🎯 对你的用处：今天已经装进云电脑实测跑通，用它出了《定投复利是怎么滚起来的》一页真成品（随本页一起发你）；以后“难问题 → 一页 HTML”的回答都走这条路，省下来的 token 与时间直接变成“每天能多讲一课”。

收费：开源免费（MIT）
来源：GitHub 仓库
https://github.com/QingYunA/answer-me-with-html

10.OpenFilm：开源 AI 视频 Agent，coding agent 直接拍视频，3,184 星

“一页 HTML、一函数、一真编辑器”：影片就是一个 film.html，轨道上剪的是网页、视频、图片、声音；每个镜头是一页用 frame(t) 函数画任意时刻的网页，three.js、WebGL、Canvas、SVG、CSS、GSAP 全能用；Studio 本地编辑器实时预览，网页里任何元素都能拖、改字、改色，改完存回影片文件，Agent 看得到、接着改。做片、剪片、渲染不需要账号。

🎯 对你的用处：漫剧标题卡、片头、转场这类“代码能画的镜头”，以后让 Agent 写 film.html、Studio 改好、渲染出片，不再是“手写 HTML 再 ffmpeg 录屏”的土办法；需要 Node 22.2+ 与 ffmpeg，云电脑已满足，列入下次漫剧生产时试用。

收费：开源免费；做片、剪片、渲染不要账号，配音、音乐、图片、视频才接自己的 Key
来源：GitHub 仓库
https://github.com/openfilm/openfilm
