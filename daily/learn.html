今日成果 · 漫剧 / 创作漫剧用

1.PhotoCraft（纯 Rust 的 Photoshop 平替）

开源图片编辑器，9 月 30 日建仓、约 3 周半已攒 72,375 个 star，本轮星数第一。号称 Adobe Photoshop 的 clean-room 复刻：图层、蒙版、调整图层、图层样式、文字、矢量、画笔全支持，还能打开编辑真 PSD 文件，全程离线、macOS / Windows / Linux / FreeBSD / Web 都能跑。和上轮学过的 FilmCraft 是同一家 storytold 的 ArtCraft 系列。

🎯 对你的用处：漫剧海报、分镜拼图、标题卡底图的修图环节有开源平替了——图层级调色、蒙版、文字排版都能在本地做，不用再找在线修图站。FilmCraft 剪辑＋PhotoCraft 修图，就是漫剧的开源工作台。

收费：开源免费（MIT OR Apache-2.0），早期 alpha 阶段
来源：https://github.com/storytold/photocraft

2.华叔艺术动画（36 种风格的代码动画 Skill）

中文艺术动画 Skill：让 coding agent 把艺术风格"写成会动的画"——36 种艺术风格、9 种解说语法、8 种参数化片段，附口播整片参考代码，一条命令 npx skills add 即装。核心案例"花叔闯进超级玛丽"（65 秒成片）里砖块、水管、关卡运动与转场全是代码完成。2026 年 10 月已被开源 AI 设计工作区 Open Design 收录为设计来源。

🎯 对你的用处：漫剧标题卡、转场、技能特效的"代码动画"路线又多一套现成风格库——《星尘逆命》集与集之间的标题卡、片头，用这套风格 Skill＋Canvas 代码做，零成本、真动态、不糊；正式镜头再走可灵/即梦。

收费：开源免费（MIT），无订阅
来源：https://github.com/alchaincyf/huashu-art-motion

3.Universal Modder（AI 给任何 PC 游戏做 Mod）

让任意 AI 编程 Agent 给你拥有的 PC 游戏做 Mod 的 Skill＋工具＋知识库：Agent 自己找游戏、判引擎、读真代码、写 Mod，再用法尔（fal）生成美术、3D、音效，在运行中的游戏里实测、剪视频，最后把经验写进知识库供下一个 Agent 用。支持 Claude Code、Codex、Cursor、Gemini CLI、GitHub Copilot、OpenCode，Mod 分享站 universalmodder.com 即将上线。

🎯 对你的用处："Agent 做游戏、经验进知识库"的打法可以直接抄——《英雄世界》《魂灵纪元》《葫芦娃》每次改版的经验（比如巨数换安全上限、禁用原生弹窗），照它的做法建成一份"游戏开发战地笔记"，下次改版 Agent 先读笔记再动手，少踩重复的坑。

收费：工具开源免费（MIT）；生成美术、3D、音效走 fal.ai，按量计费
来源：https://github.com/rehan-remade/universal-modder

今日成果 · 做网页 / App工作台用

4.Shaders（WebGPU 特效当组件用）

WebGPU 特效做成前端组件：200 多种效果（渐变、噪点、玻璃、金属、光线、扭曲、转场、模糊、光标特效……）直接当组件嵌进 React、Vue、Svelte、Solid、原生 JS。真 WebGPU、声明式 API，类型安全、支持服务端渲染；在 shaders.com 的无限画布上可视化设计，导出就是对应框架的组件树，已有 16,000 多名设计工程师在用。

🎯 对你的用处：单文件 HTML 展示页（学习成果、盘前预判、定投台）想做"液态玻璃、光线流动"这类高级视觉，不用手写 WebGPU 着色器了——在 shaders.com 上设计好导出组件嵌进去就行。注意我们交付物是"单文件内嵌、禁 CDN"的红线，用的时候要走本地内嵌构建，不能直接引 CDN。

收费：基础组件免费开源；另有 Shaders Pro 付费版
来源：https://github.com/shader-effects-inc/shaders

5.Replica Skill（11 步克隆任何 App）

11 个 Claude Skill，专门"克隆任何 App"：一个逆向原 App、一个重建、一个测 Bug，还有一个"创业家"——读原 App 用户最讨厌什么，在你的版本里修掉，做成能卖的 App。分工极细：逆向成地图、定技术栈与数据库、重建设计系统、逐屏重建、接登录与支付、命名、上架、发布全覆盖。免费、MIT、无注册、无 API Key，只复刻"功能与流程"，不碰原 App 的代码、logo、文案与内容。

🎯 对你的用处："复刻"第一次有了成体系的方法论——《英雄世界》《葫芦娃》靠"录屏对照＋逐条改"做到现在，这套 11 步分工可以直接套进下一个复刻项目。更关键的是"创业家"那一步：复刻完不要只停在"像"，要去读原 App 用户的差评、把原版最被骂的点修掉，这正是《英雄世界》从"复刻"走向"更好玩"的路。

收费：开源免费（MIT），无订阅、无 API Key
来源：https://github.com/Jakeschincariol/replica-skill

6.OpenDots（常驻型 AI 同事模板）

常驻型 AI 同事模板：每个 AI 同事（Dot）都有自己的一台电脑，在文字、电话、Slack 之间来回干活；Web 与手机端都能用，基于 CopilotKit 与 AG-UI 搭建。流程是"问一句 → 浏览 → 审批 → 保存"：聊天里直接出现 live 电脑画面与人工审核卡，批了的草稿才变成可编辑的 Space 页面。README 明说"这是起点、不是成品"，当前 alpha。

🎯 对你的用处：个人 AI 工作台的"常驻同事"形态有参考实现——"每个任务一个常驻 Dot（新闻 Dot、盘前 Dot、漫剧 Dot），各有自己的电脑与工作空间"，比"一个助手包打天下"更贴合。更重要的是它的"人工审核卡"：以后凡是 AI 要替你改东西（改文件、发消息、下单），都先弹一张审核卡让你点头，这个闸门值得写进所有自动化任务的规范。

收费：模板开源免费（MIT）；对话能力需 CopilotKit Intelligence 服务（可托管、可本地 Docker 评估、可授权自建）
来源：https://github.com/CopilotKit/OpenDots

7.DigUp（一句话从电脑里挖文件）

用一句话描述内容，就能从电脑里把文件"挖"出来：照片、PDF、文档、录音、视频全按语义搜。底层是 Google DeepMind 2026 年 10 月发布的 EmbeddingGemma 2 多模态嵌入模型：文字、图片、音频、视频进同一个向量空间，"海滩上的狗"能搜到那张照片，播客里聊睡眠的那一段也能被一句话定位；支持 100 多种语言。模型仅 7.4 亿参数，小到能本地跑，全程不上云。

🎯 对你的用处："知识库按语义搜"的本地化路线——现在查资料靠文件名与人工翻笔记（提示词库 88 条、收藏夹 111 个站、漫剧生产资料一堆），以后给本地知识库加一层"EmbeddingGemma 式语义索引"，问"上次那个调音量的办法"不用记文件名、直接按意思搜到。先记下这个模型名，等云电脑有空闲算力时搭一个本地语义搜索小工具。

收费：开源免费（MIT），模型 Apache 2.0，本地跑无订阅
来源：https://github.com/ARahim3/DigUp

8.PdfCraft（纯 Rust 的 PDF 工作台）

纯 Rust 写的开源 PDF 工作台：阅读、整理、合并、拆分、加密 PDF 的原生应用，macOS / Windows / Linux / FreeBSD / Web 全覆盖，无账号、无遥测。不只是阅读器：带"全部工具"侧栏与多人批注（示例文件里一次开了 20 条线程评论），定位是"PDF 的工作台"。和 PhotoCraft、FilmCraft 同属 storytold 的 ArtCraft 矩阵，9 月 30 日建仓、约 3 周半已攒 17,626 个 star。

🎯 对你的用处：交付物的 PDF 环节有本地工具链了——熟食制作流程表、定投复利台明细、漫剧分镜表这类要发给你看的文档，以后用 PdfCraft 做合并、拆分、批注、加密，不用再找在线 PDF 站（在线站要上传文件，有泄露风险）。

收费：开源免费（MIT OR Apache-2.0），无订阅
来源：https://github.com/storytold/pdfcraft

9.AIHOT（自己找热点、自己写日报的网站框架）

一个"自己找热点、自己写日报"的网站框架，线上原站 aihot.news 已在跑：每天从一批信源收资料，大模型先筛一遍、再独立打两次分，挑出真正值得看的，写成中文标题和摘要；把不同来源说的同一件事聚成一个事件，按热度排序，早上出一份日报。网站、后台、精选流程、聚簇与热度算法、所有提示词原文与入选门槛全公开——换信源＋换标准，就是你的行业热点站（法律、HR、金融、贵金属都已有人问）。

🎯 对你的用处："每日资讯"与"全球新闻"的精选流程可以照它升级——现在是每天人工筛 8–10 条；照 AIHOT 的"先筛一遍、再独立打两次分、同一事件聚簇"三段式，给每日新闻加一套书面精选标准（什么算热点、多少分入选、同一事件只留一条），以后换谁来筛、标准都不漂移。

收费：框架开源免费（MIT）；自己搭要一台服务器＋大模型 API 费用
来源：https://github.com/KKKKhazix/AIHOT

10.Harness²（谷歌的递归 Agent 调优框架）

Google Research 的"递归 Agent 调优"框架：模型权重不动，只优化模型外围的 harness（提示词、工具、记忆、Skill、编排），让 Agent 在没见过的新任务上也能越做越好。两层递归：任务层用"提议改法 → 同任务上实测 → 按行为对比合成更优 harness"，不需要标准答案也能调优；harness 层把每次学到的经验沉淀进"改进 harness"，下个任务直接受益。有论文支撑（arXiv:2610.14224），三套专业基准实测：单步调优即可提升 GLM-5 与 Gemini 3.5 Flash 的表现。

🎯 对你的用处：把"调优 harness"的方法论写进漫剧与 App 的生产规范——我们现在的做法（分镜表、台词工程、质检清单）本质上就是"手工调 harness"；按 Harness² 的思路，每次生产完把"这次哪里翻车、下次怎么改"写成一条可复用的经验，进生产资料包的"改进清单"，而不是只记在聊天记录里。

收费：开源免费（Apache 2.0），研究代码无订阅
来源：https://github.com/google-research/harness2
