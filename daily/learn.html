今日成果 · 图像生成漫剧/海报用

1.Canva Craft（Canva 首个自研图像模型）

10 月 22 日上线：Canva 自己的图像生成模型，不拿照片训练、拿数百万张人类设计模板训练，天生懂版式、层级和排字；DesignArena 首秀空降全球第 4，人像、风景类目第 1。

  • 两阶段生成：先按提示词"规划版式"（元素位置、大小、视觉层级、文字），再渲染成图，文字渲染更准、局部可改不改全局；
  • 最高 2K 分辨率、30 多种画幅比例，直接出社交媒体/海报/菜单/演示文稿规格；
  • 全平台用户即日起在 Dream Lab 可用，API 和 MCP 接入在路上。

🎯 对你的用处：漫剧海报、小说章节封面、反推提示词包宣传图、店铺活动海报——文字准确＋版式天生，直接出成品不用再手动拼字；以后还能让助手通过 Canva MCP 直接生成可编辑设计稿。

收费：随 Canva 会员体系，未公布独立定价；低成本版 Craft-fast / Craft-ultrafast 开发中
来源：petapixel.com（2026-10-23）

2.Nano Banana 2.1（Google，10 月 6 日正式版）

Google 新一代图像生成/编辑模型，基于 Gemini 3.6 Flash；价格砍到上一代约一半，老版 Nano Banana 2 已于 10 月 29 日关停。

  • 文生图＋图生图编辑同一模型搞定，延续 Nano Banana 系的强编辑能力；
  • 1K 图片约 0.0336 美元、2K 约 0.0504 美元（标准档），走 batch 再半价；
  • 注意：512px 便宜缩略图档取消，以前拿它出草图的路子没了。

🎯 对你的用处：魂灵纪元建模参考图、漫剧分镜草图的"出图引擎"可以从 2.0 切到 2.1，成本直接减半；AI Studio 里免费用它批量出参考图。

收费：按张计费，1K 约 0.0336 美元；免费额度走 Gemini App / AI Studio
来源：tech-insider.org（2026-10-29 实测文）

今日成果 · 大模型写代码/做分析/跑Agent

3.GPT-6.1 Terra（OpenAI，10 月 26 日）

OpenAI 新"中坚工作马"：办公、电脑操作、视觉推理、写作任务上对标旗舰 GPT-6 Astra，token 价格只有十分之一；已进 GitHub Copilot 做 agentic coding。

  • 为多步骤 Agent 工作流优化：代码、填表、终端自动化，错误诱发提示的出错率从 53.6% 降到 16.7%；
  • 105 万 token 上下文、12.8 万输出上限；
  • 可用在 API、ChatGPT Work、Codex 和 GitHub Copilot。

🎯 对你的用处：以后跑自动化任务（定时抓数、批量改网页）的模型成本能砍一大半；云电脑上跑 Agent 活儿优先选这类"便宜快"的中坚模型，不用事事上旗舰。

收费：$1 / $5 每百万输入/输出 token（前代一半）；缓存输入 $0.05
来源：asumetech.com、local-ai-zone.github.io

4.Nvidia Nemotron 3.5 Super VL（英伟达，10 月 15 日，开源）

120B 参数（每 token 只激活 12B）的开源多模态 MoE，号称同类开源模型里 Agent 任务完成速度快 5 倍；权重 Day 0 就上了 Hugging Face。

  • 文/图/文档/视频一个模型全吃，100 万 token 上下文，不用来回切模型传上下文；
  • Agent 任务输出超 600 token/秒，Agent 评测里反超自家旗舰 Nemotron 3 Ultra；
  • 开源 OpenMDW 协议，可用 NeMo 在自己数据上继续训练（官方演示：医疗理赔任务微调后反超 Claude Opus 5）。

🎯 对你的用处：云电脑 dsh 免费池的"不敏感活儿"多了一个强力备选——开源意味着 prompt 不经过商业 API，隐私顾虑更小；以后自建的 Agent 工具链可以考虑它当执行引擎。

收费：权重免费下载，自己部署只花算力；配套有 Bolt 74B（24GB 显存本地跑）和 Bolt E4B（4GB，手机级对话 Agent）
来源：aitrove.ai

5.Mistral Large 4「Le Chonk」（10 月 29 日刚开源权重）

法国 Mistral 的万亿参数（每 token 激活 52B）多模态 MoE，10 月 6 日预览、10 月 29 日放出开源权重，改良 MIT 协议。

  • 文本＋图像输入、100 万 token 上下文；
  • 权重开源可本地部署、自己微调；
  • 欧洲开源旗舰，独立评测 Intelligence Index 38 分（中等偏上，非顶级）。

🎯 对你的用处：dsh 免费池/OpenCode 车道的又一个"不花钱或少花钱"的大模型选项；本地化部署后，知识库问答、提示词库检索这类活儿可以不走云端 API。

收费：预览 API $1.36 / $4.18 每百万 token；权重免费下载（注意商用条款）
来源：pasqualepillitteri.it、siliconainews.com

6.Gemini 4 Carbon（Google，10 月 28 日预览）

Google 当前最强模型，为网络安全和超长任务打造；独立评测 Intelligence Index 59 分登顶（52 个模型第 1，比 Claude Opus 5.5 高 1 分）。

  • 网络安全专项能力＋超长任务续航；
  • 分阶段开放：先给网络安全防御者，再给可信伙伴，暂无公开 App/API；
  • 首发价 $2 / $10，12 月 1 日后涨到 $4 / $20。

🎯 对你的用处：暂时用不上，但它是"下一代 Gemini 进 Gemini App/Workspace"的预告——等它下放到消费端，盘前预判、研报总结这类长文档活儿可以直接换更强底座；选型时留好升级路径。

收费：目前不公开售卖；首发 $2 / $10 每百万 token
来源：siliconainews.com（AI 模型发布追踪）

今日成果 · Agent 与开发平台自动化用

7.Gemini Agent（Google Cloud，10 月 8 日发布、私测中）

Google 的"通用智能体"：一个入口搞定聊天问答、多步骤自主任务、内容创作、写代码；原生接 Gmail/Docs/Drive/Sheets/Calendar，还能连 Slack 和 Microsoft 365。

  • 给目标不给指令：规划→调用工具→协调子智能体并行干活，可连续跑几小时甚至几天，跨会话不断记忆；
  • 每个 Agent 有独立身份、日历和存储，能当"团队成员"长期在线；
  • 10 月 21 日更新：多模型自动路由、实时项目花费上限（到上限自动暂停）。

🎯 对你的用处：这就是"云端小坏蛋"的官方版形态——定时抓盘前数据、整理 Gmail、更新知识库，未来可能直接在 Google 生态里配一个长期在线的 Agent 干；现在私测，公测后第一时间试用。

收费：Google 未公布；第三方称约 $30/用户/月（未证实）
来源：tech-insider.org

8.前 GitHub CEO Thomas Dohmke 新平台（10 月 26 日上线）

GitHub 前 CEO 另起炉灶做的"AI 原生"代码协作平台：AI Agent 不是插件，是和人类平级的协作者；限量开放＋候补名单，2027 年初正式版。

  • Agent-first 架构：Agent 有独立工作区、持久记忆，和人类用同一套版本控制原语；
  • 兼容标准 Git 协议，另加 Agent 专用操作（批量重构、自动依赖更新）；
  • 多模态代码评审＋针对 AI 高频提交优化的实时冲突解决；按 Agent 用量计费、不按人头。

🎯 对你的用处：AI-wealth-assistant 仓库和商城项目以后可能迁到这类平台——Agent 直接当协作者提交代码、修 bug，不用再人肉搬运；现在先候补名单占位，2027 年初正式版再评估。

收费：未公布，按 Agent 用量计费；云端＋自托管两版
来源：emergent.sh

今日成果 · 语音与世界模型配音/游戏用

9.Nemotron 3.5 Transcribe（英伟达，10 月 28 日，开源）

开源语音转文字模型：40 种语言转写、31 种语言↔英语互译、最多区分 8 个说话人，商用免费，可本地部署。

  • 录音转文字 40 语言（含中文），31 种语言与英语互译；
  • 说话人分离（最多 8 人）——会议/多人配音转写直接分段到人；
  • OpenMDW-1.1 协议，商用免费。

🎯 对你的用处：配音质检的转写环节（现在用 faster-whisper）多了一个开源备选；每日英语课、讲书语音的字幕生成也可以走它；本地部署后长音频转写不花钱、不用传云端。

收费：权重免费下载，商用免费；自己部署只花算力
来源：siliconainews.com（AI 模型发布追踪）

10.Genie 4（Google DeepMind，10 月 27 日预览）

DeepMind 新一代"世界模型"：一句话实时画出可交互场景，带声音、带会说话的角色；受信测试者研究预览中。

  • 文本提示实时生成可交互 3D 场景，角色能对话、有环境音；
  • 场景可"驾驶"：边生成边改，适合快速验证玩法和镜头；
  • Google AI Ultra 订阅者和 Gemini API 伙伴随后开放。

🎯 对你的用处：游戏（魂灵纪元/英雄世界）的新玩法、新地图可以先让 Genie 4 生成可玩原型验证手感，再决定投不投入建模；漫剧分镜也可以先"走"一遍场景看机位；开放后第一时间申请测试。

收费：未公布
来源：siliconainews.com（AI 模型发布追踪）
