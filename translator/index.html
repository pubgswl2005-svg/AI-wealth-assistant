河马的专属翻译

像流利阅读（FluentRead）那样双语对照，但不只限于浏览器：整个手机的英文界面都能翻成中文。主界面直接打英文、立刻翻；去别的 App，点悬浮球就翻本屏。

📱 全手机翻译：先开这一步（只设一次）

  1. 点下面 去开启无障碍，在系统设置里找到 河马的专属翻译，打开开关。
  2. 回到任意英文 App（比如你截图那个 GitHub 页面），屏幕上会出现蓝色 “译”悬浮球，球可以拖到不挡字的地方。
  3. 点球 → 弹出全屏双语对照面板：上面是英文原文，下面是大字中文，面板里能复制全部中文、刷新、关闭。

当前状态：未知，点“检查”看一下

🔴 注意：这是安卓系统规定的安全步骤，App 自己不能偷偷替你打开，必须你本人在设置里点一下开关。另外银行、支付类安全窗口和图片里的英文、视频字幕，系统不让抓，v1 翻不了，这是系统限制不是 Bug。

灵感来源：开源项目流利阅读 FluentRead（浏览器双语翻译插件，官网 read.thinkstu.com/，仓库 github.com/FluentRead/FluentRead），本 App 是把它“整页双语”的做法搬到整个手机上，不是照搬它的代码。
