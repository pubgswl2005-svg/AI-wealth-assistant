今日成果 · 视频生成漫剧制作

1.Vidu Q4 Preview：生数新一代视频模型，4K + 10-bit 色彩

生数科技 10 月 7 日公开预览。图生视频 / 参考图生视频，单条 3–16 秒、24fps，保留原图比例；最高 4K 分辨率 + 10-bit 色彩（10 亿色级别），肤色、光影渐变更平滑；自然语言指挥运镜（推、摇、移多镜头描述），多人同框的大幅度动作保持稳定，面部表情更细腻。暂不支持纯文生视频。

🎯 对你的用处：漫剧分镜图可以直接喂给它转动态片段，4K 画质正好对上“不要糊糊的感觉”这条红线；图生视频 11 月 30 日前 7 折，适合先小批量试镜。

收费：$0.045/秒（540p）至 $0.39/秒（4K）；图生视频与参考图生视频 2026 年 11 月 30 日前 7 折
来源：Business Wire 10月8日
https://www.businesswire.com/news/home/20261008695498/en/

2.Wan 3.0：阿里通义万相视频 API，按秒计费、不用申请

阿里云 Model Studio 上线的视频生成 API，无需申请直接调用。文生视频与图生视频，时长 2–30 秒，480p / 720p / 1080p 三档；按秒计费、价格透明：480p $0.05/秒、720p $0.10/秒、1080p $0.20/秒（国际站价），国内价 0.30 / 0.60 / 1.20 元每秒。

🎯 对你的用处：漫剧批量出镜时最省事的“按量付费”备选——先用 480p、每条 30 秒 $1.50 出小样筛镜头，定稿再升 1080p；比包月制更适合“一个月只集中做几天漫剧”的节奏。

收费：按秒计费，480p $0.05/秒、720p $0.10/秒、1080p $0.20/秒
来源：Tech Insider 10月23日实测指南
https://tech-insider.org/ai-video-generator-benchmark-harness-12-steps-2026/

3.iAsk.ai 搜索转视频：提一个问题，直接生成讲解视频

AI 搜索平台 iAsk.ai 10 月 26 日上线的新功能。在首页提问时勾选“Generate a tutorial video”，问题本身就是视频主题，无需写脚本、分镜；视频与文字答案、来源引用、追问并列展示，可反复回看；面向所有用户开放。

🎯 对你的用处：学新东西最快的“先看一遍再动手”入口——比如问“存储芯片为什么涨价”“定投怎么选”，直接得一段讲解视频；也可以用来给熟食店员工做简短培训视频的素材参考。

收费：该功能面向所有用户开放（官方通稿未单独标价，iAsk.ai 基础搜索免费）
来源：Morningstar / ACCESS Newswire 10月26日
https://www.morningstar.com/news/accesswire/1240329msn/iaskai-unveils-search-to-video-ai-ask-a-question-watch-the-answer

今日成果 · 图像生成与编辑分镜与海报

4.Ideogram 4.5：只改一处、其余不动的图像编辑模型

Ideogram 10 月 1 日上线。主打局部编辑：换衣服、改图中文案、换背景，只动指定区域，未改区域多轮编辑后仍保持原样，减少“越改越跑偏”的累积漂移；原生 2K 输出，图内文字渲染是强项；已上线自家平台与 API，合作方包括 Picsart、Runway、Pika、Leonardo AI。

🎯 对你的用处：漫剧分镜图、海报、熟食店招牌图最怕“改一句文案整张脸就变了”——这个模型就是冲着这个痛点来的；修一张产品图反复改文案也不用重画整张。

收费：按张计费，四档 0.8–22 美分/张（按画质档位）
来源：The Decoder 10月1日
https://the-decoder.com/ideogram-says-its-new-model-can-edit-part-of-an-image-without-messing-up-the-rest/

5.FLUX 3 Image Klein：5.6B 开源图像模型，8GB 显卡就能本地跑

Black Forest Labs 10 月 15 日发布。文生图 + 图像编辑，最多支持 10 张参考图，适合固定角色 / 固定风格的多图一致性；原生 4K 输出，FLUX Kommunity License 开源权重；INT8 量化版可在 8GB 显存消费级显卡上运行，本地部署门槛低。

🎯 对你的用处：漫剧角色四视图参考板、固定角色多镜头的“脸不崩”利器——开源可本地跑，不用按张付费；云电脑有 GPU 时可直接装来批量出分镜图。

收费：权重开源免费（FLUX Kommunity License）；托管 API 另有按张计费（FLUX 3 Image 全系列 $0.041–0.607/张）
来源：Digital Applied 10月 AI 模型发布追踪
https://www.digitalapplied.com/blog/ai-model-releases-october-2026-tracker

今日成果 · 大模型写代码与做分析

6.Kimi K3.1 Pro：月之暗面新旗舰，100 万上下文

月之暗面 10 月 23 日发布。2.8 万亿参数（104B 激活），100 万 token 上下文，可一次吞下整个代码库或一整套财报做长程分析；独立 Artificial Analysis 指数 55 分（全部模型第 4），官方称在编码、3D 创作、金融研究三方面重点提升；另有 2–3 倍速的 Highspeed 版；开源权重 11 月 4 日放出。

🎯 对你的用处：做投资分析时一次喂多份研报、财报、持仓数据做交叉核对；写游戏 / 工作台代码时一次读完整仓库；等 11 月 4 日权重放出后可本地部署，不敏感的活不用走付费 API。

收费：API $2 输入 / $10 输出每百万 token；Highspeed 版 $4/$20
来源：Capital & Compute 10月模型汇总
https://capitalandcompute.net/blog/new-ai-models-october-2026/

7.Claude Haiku 5.5：Anthropic 最便宜的新默认小模型

Anthropic 10 月 7 日发布，已成 Claude Code 默认 Haiku 模型。定价 $0.10 输入 / $0.50 输出每百万 token（10 万 token 以内提示词），比 Haiku 4.5 便宜约 75%；独立 Artificial Analysis 指数 43 分，每任务成本 $0.21，是批量摘要、分类、子 Agent 任务的新默认选择。

🎯 对你的用处：每天自动学习、新闻摘要、持仓日报这类“量大但单条不难”的活，用它跑成本最低；写提示词模板、批量改文案也可以先拿它试，贵模型只留给真正难的任务。

收费：API $0.10/$0.50 每百万 token（10 万 token 内；超限后涨 5 倍）；Claude Pro 订阅（约 $17/月起）内可用
来源：Capital & Compute 10月模型汇总
https://capitalandcompute.net/blog/new-ai-models-october-2026/

8.MiniMax M3.1 Flash：开源权重、每任务 $0.22 的便宜大模型

MiniMax 10 月 19 日发布、10 月 23 日放出权重。428B 总参数（23B 激活），原生多模态：文本、图像、视频输入都支持；100 万 token 上下文；独立 Artificial Analysis 指数 43 分，与 Claude Haiku 5.5 同分，每任务成本 $0.22；开源权重已上 Hugging Face 与 ModelScope。

🎯 对你的用处：云电脑上能本地跑的便宜大模型备选——做视频脚本、写代码、批量处理文档都不用按量付 API 钱；100 万上下文同样适合长文档分析。

收费：API $0.15 输入 / $0.60 输出每百万 token；权重开源免费（社区许可证，要求注明“Built with MiniMax M3.1-Flash”）
来源：Capital & Compute 10月模型汇总
https://capitalandcompute.net/blog/new-ai-models-october-2026/

今日成果 · 办公提效与语音知识变现与配音降本

9.Adviserry：把邮箱通讯和 YouTube 变成每周行动清单

10 月 5 日上线。接入 Gmail 一次，自动收录已有通讯；YouTube 频道新视频发布即转录入库；按主题（如定价、招聘、投资）分面板归档，全文可搜索；每周按你告诉它的在做项目起草行动清单，每条行动都注明出自哪期通讯或哪个视频；带 MCP 服务器，Claude Desktop、Claude Code、Cursor 可直接查你的归档。

🎯 对你的用处：每天全球新闻、盘前预判、投资研报读得多但用得少——这类工具就是把“读过”变成“下周要做的事”；MCP 接入后，助手这边也能直接查他读过的资料，不用他再转发。

收费：Core $14.99/月（2 个面板）、Pro $24.99/月（5 个面板）、Team $99.99/月（5 席）；7 天免费试用
来源：Adviserry 官网 / OpenAIMaster 10月工具盘点
https://adviserry.com

10.VoiceStudio：完全本地的开源语音工作室

10 月初登顶 GitHub 趋势榜第一的开源语音工具（一周新增 16,775 star，总计 52,940）。声音克隆与声音设计、视频配音、听写、转录、批量生成，桌面 App（macOS / Windows / Linux）+ 本地 API + MCP 服务器；多个可切换的本地语音与转录引擎，声音、项目、输出默认全留本机。

🎯 对你的用处：漫剧配音、每日一书语音版目前走云端 TTS——这个是“本地平替”路线：角色声音克隆后存在本机反复用，不按分钟计费；敏感录音不上传也合规矩。注意：本地跑要够用的显卡 / 磁盘，先在云电脑上试装再决定。

收费：开源免费（AGPL-3.0）；成本只有自己的硬件与 setup 时间
来源：GitHub 项目仓库 / OpenAIMaster 10月工具盘点
https://github.com/shashushashank85-blip/shashankvoicestudio
